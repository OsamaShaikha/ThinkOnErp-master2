🌐 الرابط الأساسي (Base URL)

http://localhost:5000 أو مسار الخادم المعتمد.

🔑 الترويسات الإجبارية (Headers)

Authorization: Bearer {JWT_TOKEN}

X-Company-Id: {CompanyId} (لتوجيه البيانات للشركة).

Content-Type: application/json

جميع المخرجات مغلفة بـ ApiResponse<T> وتحتوي على success, statusCode, data, message.

🔄 الحقول الجوهرية المضافة على أسطر القيود والسندات MODIFIED
اسم الحقل في الـ JSON النوع (Data Type) إجباري؟ الوصف والوظيفة لشاشة الـ UI
branchId number / null اختياري معرف الفرع للسطر: لتسجيل حركات بين الفروع (Inter-branch Allocations).
partyType string / null إجباري عند حساب مراقبة نوع الطرف: "CUSTOMER" (عميل)، "VENDOR" (مورد)، "EMPLOYEE" (موظف)، "OTHER".

costCenterCode string / null اختياري مركز التكلفة التحليلي: رمز مركز التكلفة المرتبط بالسطر.
