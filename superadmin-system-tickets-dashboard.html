System ticket structure

Tickets are stored as request tickets with company, branch, requester, optional assignee, type, priority, status, category, SLA dates, comments and attachments.

SuperAdmin uses the same /api/tickets API, but with isSuperAdmin=true. Use this page to filter by company/branch, run AdminOnly reports, assign tickets, and check SLA.

  • List: GET /api/tickets
  • Details: GET /api/tickets/{id}
  • Types: GET /api/ticket-types
  • Reports: /reports/volume, /reports/sla-compliance, /reports/workload
