# ATT-07 — إيصال الموبايل وحماية الدليل

5 نوفمبر 2026. كود ومخطط DEV_TEMPLATE فقط؛ لا نشر تطبيق أو تحديث عميل موبايل.

## العقد الجاري

POST api/hr/attendance/check-in وcheck-out يحتاج eventId UUID ثابتاً لكل حدث، وإحداثيات JSON صريحة. يخزن المستودع raw وJSON الإيصال معاً داخل معاملة ReadCommitted لاستقبال الدليل، بقفل الموظف والتحقق من النطاق وإعادة فحص المفتاح. عند امتلاك المعاملة يلتزم بها قبل استدعاء المعالج المالي المشترك مع الأجهزة. معاملة خارجية للاختبار تنضم إلى المسار وتظل مسؤولية مالكها.

البصمة المسموحة تعيد **HTTP 202** وSuccess=true وEvidenceOnly=true وRawEventId. هذا إقرار حفظ الدليل؛ لا يعني اكتمال الحساب المالي. حتى إذا نجحت المعالجة الفورية يظل الإيصال الأصلي كما هو. يجب تحديث مستهلك الموبايل لقبول 202 وحفظ eventId ومتابعة حالة اليوم أو GET raw-events/{id}?employeeCode=... لمعرفة النتيجة. EventResponseJson وبصمة المحتوى لا يظهران في API قراءة الدليل.

الرفض وفق الموقع/سياسة الفرع يحفظ دليلاً نهائياً REJECTED مع السبب والمراجع والتوقيت وإيصال HTTP 400 وRawEventId؛ لا يُطبق مالياً. الإدخال غير الصالح أو عدم الصلاحية لا يتحول إلى دليل مصرح به. إعادة نفس الطلب المقبول أو المرفوض تعيد بيانات الإيصال الأصلية دون حفظ آخر أو محاولة حساب جديدة، حتى بعد الإقفال أو تغير الإعداد. تغيير المحتوى بنفس المعرف يرجع 409. غلاف API العام قد يختلف بتوقيت الطلب؛ Data المخزنة هي التي يعاد استعمالها.

## الفشل والمراجعة

رفض CLOSED أو مسير معتمد، غياب إعداد توقيت الشركة، أو تعذر الحساب يبقي raw معلقاً وإيصاله ثابتاً. LastAttemptedAtUtc وLastAttemptedBy وProcessingReason تعرض آخر محاولة وسبب تعذرها؛ الخطأ غير المتوقع يسجل نوعه دون تفاصيل الاتصال ويعرض سبب مراجعة عام. إلغاء اتصال العميل قد يقطع الرد بعد الحفظ؛ إعادة الطلب بنفس eventId تستعيد الإيصال. لا عامل background منشور؛ يستعمل المخوّل طابور المعالجة الصريحة.

المعالج المالي نفسه يملك أقفال الفترات/الموظف وإعادة الحساب وربط raw باليوم. لا تغير محاولة إعادة إيصال يوم الحضور أو تتجاوز القفل. يستطيع المخول تجاهل raw المعلق بسبب موثق دون حذف الدليل؛ لا يمكن تجاهل دليل مطبق أو فكه عن يومه. رفض تصحيح PENDING بسبب موثق يقفل الموظف والطلب دون الفترة المالية، لذلك يعمل عند CLOSED. الموافقة تبقى كتابة مالية تحت حارس الفترة ونسخة اليوم.
