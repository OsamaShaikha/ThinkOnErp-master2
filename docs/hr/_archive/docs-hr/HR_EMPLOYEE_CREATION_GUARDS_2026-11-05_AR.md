# EMP-11 — حماية إنشاء الموظف المباشر

CreateEmployeeAsync يمر الآن بمعاملة حماية مدخلات الموظف نفسها المستعملة لاستيراد Excel: هوية الموظف المطبعّة، الشركة/الفرع وتاريخ التعيين، ثم أقفال الفترات المتأثرة وفحص CLOSED والمسيرات المعتمدة للفرع قبل callback أو إضافة الموظف. التحقق من تكرار الرمز/الهوية يبقى داخل المعاملة؛ قيد المفتاح هو الحارس النهائي لإدخال متزامن. غياب unit of work يرفض المسار بدل حفظ غير محمي.

استُخرج ExecuteEmployeeInputsAsync<T> لتوحيد منطق الأقفال دون تغيير عقد الاستيراد: الاستيراد يملك معاملته ويرفض الخارجية، ويتراجع عن الملف كله عند Errors. الإنشاء يملك ReadCommitted عادة ويمكنه الانضمام إلى ReadCommitted خارجية للتنسيق/التجربة؛ مالكها مسؤول عن rollback. لا يغير الموظفين الموجودين عند تكرار رمز الإنشاء.

للإنشاء حارس إضافي لمسير APPROVED/POSTED_TO_GL/PAID في الفرع بلا PayrollPeriod مطابق؛ لا يمكن تخمين مدى تاريخه لإضافة موظف جديد بأمان. اكتُشفت هذه الحالة في بيانات DEV_TEMPLATE الأصلية ولم تُعدّل أو يُفتح مسير أصلي لحلها. مراجعتها/ربطها في OPS-03 مستقلة عن هذا المسار. تستمر حماية الإعدادات/النطاق في فلتر HTTP وعند الحفظ، ولا يستبدل هذا العمل تدقيق حقول EMP-01 أو العلاقة الإدارية EMP-02.

نجح **320 اختبار HR** بعد EMP-11، منها بوابة ترفض الإنشاء قبل أي إضافة وcallback مسموح يطبع الرمز ويحفظ مرة واحدة، مع بقاء اختبارات الاستيراد والراتب السابقة ناجحة. نجح Oracle/rollback عبر خدمة الإنشاء الحقيقية: رفض عند CLOSED دون صف جديد، ورفض فرع ذي مسير معتمد بلا فترة، ثم إنشاء مسموح في فرع حالي خالٍ من التعارض. استعملت التجربة فرعاً مناسباً بدلاً من تغيير المسير الأصلي؛ تراجعت جميع البيانات وتحقق غياب الموظف التجريبي وعودة بيانات المصدر. نجح فحص EMP-05 و59/59 جدولاً أصلياً ضمن نفس التشغيل.

الأدلة emp11-hr-suite.log وemp11-oracle-final.log؛ الأمر --verify-employee-profile يثبت مساري التعديل والإنشاء. لا DDL لهذه الحزمة، ولا HTTP لإنشاء الموظف على Oracle أو جلستان متزامنتان أو commit ذاتي مثبت. لا نشر أو مزامنة عميل.

تحديث 6 نوفمبر: [عقد تدقيق مدخلات الموظف وExcel](HR_EMPLOYEE_INPUTS_2026-11-06_AR.md) يوحد الحقول والتواريخ والهوية وسعة النصوص؛ إنشاء TERMINATED يتطلب تاريخ إنهاء، والحماية المالية للملف غير المؤرخ مستمرة.
