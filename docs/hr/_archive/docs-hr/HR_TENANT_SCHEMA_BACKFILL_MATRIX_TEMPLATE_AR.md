# قالب مصفوفة فروق مخطط المستأجر وقرارات backfill

**الحالة:** قالب متابعة؛ لم تكتمل مصفوفة الأعمدة ولم تُنفذ مزامنة أو DDL/DML.
**خط الأساس:** تقرير القراءة فقط المؤرخ 6 نوفمبر 2026 بين `DEV_TEMPLATE` والتقرير التاريخي لـ`THINKONERP_DEV02`.
**قيود الاستخدام:** لا يُعاد استخدام DEV02 أو أي مخطط عميل قبل توثيق العزل والإذن والنسخة القابلة للاستعادة. هذا الملف لا يحتوي أسماء أعمدة مستنتجة ولا قيم backfill مخمنة.

## حقول المصفوفة التنفيذية المطلوبة لكل عمود من الأعمدة الـ199

| الحقل | ما يجب تسجيله |
|---|---|
| الهوية | اسم المخطط التجريبي المعزول، اسم الجدول، اسم العمود، بصمة تقرير المصدر والهدف وتاريخهما |
| تعريف المصدر والهدف | Oracle data type، precision/scale، byte/char length semantics، nullable، default، identity/virtual إن انطبق |
| الاعتماديات | PK/FK/UNIQUE/CHECK والفهارس/المشغلات التي تعتمد على العمود مع تعريفها وترتيب الأعمدة |
| backfill | مطلوب/غير مطلوب، مصدر موثوق، قاعدة تحويل قابلة للتكرار، عدد الصفوف، عدد القيم غير القابلة للتحويل، استعلام تحقق |
| قرار البيانات | مالك قرار القيمة، قبول المؤقت nullable إن انطبق، الموافقة وتاريخها، سبب القرار |
| التنفيذ والقبول | DDL/DML المخطط، اختبار أولي، نتيجة ما بعد التطبيق، قرار rollback وبصمة النسخة |

### تصنيف الأعمدة `NOT NULL` بلا default (120)

لا يمكن تعبئة صفوف التصنيف قبل استخراج أسماء الأعمدة من preflight تفصيلي جديد؛ التقرير التاريخي لا يسميها. لكل عمود من هذه المجموعة يجب تسجيل: **اسم الجدول والعمود، عدد الصفوف المتأثرة، هل توجد قيم تاريخية موثوقة، مصدرها، قاعدة التحويل، صفوف الفشل، مالك القرار، قبول nullability مؤقتة أو رفضها، ونتيجة اختبار backfill**. يمنع وضع قيمة ثابتة لكل السجلات أو خفض القيد تلقائياً. إذا لم يوجد مصدر موثوق، يتوقف تطبيق الجدول ويُرفع قرار بيانات.

## بوابة الانتقال إلى مصفوفة مكتملة

1. الحصول على موافقة موثقة لنسخة مخطط معزولة وقابلة للاستعادة؛ لا اتصال أو كتابة إلى `THINKONERP_DEV02` ضمن هذا القالب.
2. توليد مخرجات metadata per-column للمصدر والهدف، دون بيانات شخصية، مع بصمات وتاريخ الفحص.
3. إدخال 199 فرقاً فردياً وربط كل فرق بتعريفه وقرار DDL؛ تمييز الأعمدة الـ120 الحرجة صراحة.
4. طلب قرارات backfill من مالكي البيانات؛ إبقاء ما لا مصدر له متوقفاً بدلاً من التخمين.
5. استكمال مطابقة القيود والفهارس ومراجعة seed المحاسبي وخطة النسخ/الرجوع حسب `HR_TENANT_SCHEMA_MIGRATION_PLAN_2026-11-12_AR.md`.
