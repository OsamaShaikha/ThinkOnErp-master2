# EMP-03 — مراجعة ربط حساب الموظف

6 نوفمبر 2026. مراجعة أولية بعد حزمة كتالوج EMP-02؛ المهمة جزئية ولا تُغلق بهذه الاختبارات.

الربط UserId اختياري وفريد في HR_EMPLOYEE، وعلاقة EF تمنع الحذف المتسلسل. قراءة me/user-link تعتمد هوية المصادق عليه ولا تقبل هوية بديلة من الطلب. تغيير الربط عبر EmployeesController يتطلب AdminOnly وفلتر HR الحالي؛ علاقة ManagerEmployeeCode أو الأب التنظيمي لا تمنح صلاحيات.

الخدمة الحالية ترفض الحساب غير المتاح/غير الفعال أو غير المخول لفرع الموظف، والموظف غير الفعال، والمعرف غير الموجب، وربط الحساب بموظف آخر. إعادة نفس الرابط مسموحة؛ إلغاء الربط لا يحذف الموظف ويظل ممكناً للمنتهي. تُحجب علاقة Employee.User من JSON لمنع تسريب بيانات الحساب. لا يعني ربط حساب منح المدير عرض فريقه أو الراتب والبنك.

أُدخلت اختبارات EmployeeUserLinkTests وEmployeeUserLinkModelTests واختبارات المتحكم الموجودة إلى التشغيل المركّز، بدلاً من بقائها خارج أمر التحقق المعتاد. هذه فحوص وحدات/نموذج وعقد مباشر؛ لا تدعي تشغيل ربط حساب عبر Oracle HTTP أو جلسات متزامنة.

## العمل التالي

أُنجز تنسيق الربط ضمن [EMP-13](HR_EMPLOYEE_ACCOUNT_GUARDS_2026-11-06_AR.md): بوابة معاملات/أقفال، إعادة قراءة الحالة والفرع، وحفظ حقول الرابط فقط. بقيت البصمة الحالية كما هي؛ تغيير الرابط الحقيقي يحتاج إعادة حساب المسير المحسوب قبل الاعتماد، ولا يهاجر بصمات قديمة أو يفتح CLOSED. أُضيف فحص جلستين فعليتين لحجز القفل وتسلسل دخول الحارس؛ بقية التزامن مستقلة.

تبقى مراجعة صلاحيات المدير/الفريق، فصل حقول EMP-04 الحساسة، HTTP بمنح فعلية وبمخططَي عميلين، واختبار التزامن ضمن EMP-03 وBASE-04 وOPS-04/05. لا تعديل أدوار أو حسابات أو روابط أصلية في هذه الحزمة.

المجموعة الموسعة ناجحة:363 HR و86 عقد/فلتر/HTTP، مع بقاء الاختبارات المركزة منفصلة عن اختبارات المستودع العامة. لا يضيف عدد الاختبارات مهام مكتملة تلقائياً.

أُضيفت لاحقاً [قراءة الفريق المباشر](HR_EMPLOYEE_TEAM_2026-11-06_AR.md) بمنح مستخدم/دور صريحة وإسقاط محدود؛ تبقى مصفوفة أفعال المدير وOracle HTTP منفصلتين.
