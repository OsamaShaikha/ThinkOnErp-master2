التحليل الجذري لأخطاء الخادم الـ 62 (Status Code 500) وحلولها البرمجية

🏢 1. صلاحيات شاشات الفروع (15 خطأ في Company Management)
تحدث عند استدعاء مسارات /api/branches/{id}/access/* و /api/branches/{id} بسبب محاولة قراءة صلاحيات الشاشات المخصصة للفرع 1، حيث يرمي الـ Handler استثناء NullReference أو عدم وجود السجل في جدول الربط.
الحل: إضافة Null check في GetBranchQueryHandler والتأكد من إرجاع قائمة فارغة عند عدم وجود شاشات مخصصة بدلاً من رمي Unhandled Exception.
💰 2. الحسابات البنكية وأنواع السندات (31 خطأ في Accounting API)
تحدث في مسارات البنوك مثل /api/accounting/banks/account-numbers/lookup وحذف أنواع القيود والسندات، وتعود إما لعدم تطابق نوع البيانات مع Oracle أو وجود Foreign Key غير ممسوك عند الحذف في MediatR.
الحل: تغليف عمليات الحذف بـ Try-Catch ترجع ConflictResult أو BadRequestResult مع رسالة واضحة للمستخدم بدلاً من الخطأ 500.
🛒 3. طابعات نقاط البيع وتجهيز الوجبات (6 أخطاء في POS API)
تحدث في مسارات توجيه الطابعات /api/pos/printer-routings/category/{categoryId} و /api/pos/batches/prepare بسبب عدم وجود تعريفات الطابعات للفرع في قاعدة البيانات.
الحل: إرجاع مصفوفة فارغة [] عند عدم وجود طابعات مرتبطة بدلاً من رمي خطأ داخلي.
🎫 4. مرفقات التذاكر والدعم الفني (6 أخطاء في Tickets API)
تحدث في مسارات إضافة مرفقات التذاكر /api/tickets/{id}/attachments لعدم تمرير File Stream كـ Multipart Body أو عدم وجود مجلد التخزين المؤقت.
الحل: التحقق من وجود الملف في الـ Request وإرجاع 400 Bad Request في حال عدم إرسال مرفق.
👥 5. تقويم العمل وسلف الموظفين (4 أخطاء في HR & Payroll API)
تحدث في مسارات تقويم الدوام وسلف الموظفين /api/hr/employees/{id}/loans و /api/hr/work-calendars/{id} بسبب دوران مرجعي (Reference Cycle) في EF Core أثناء التسلسل إلى JSON.
الحل: تفعيل ReferenceHandler.IgnoreCycles في إعدادات JSON الخاصة بالـ Controllers أو استخدام DTO مسطح.
🌐 6. ملاحظة مهمة: مشكلة لغة رسائل الخطأ عند تسجيل الدخول
عند فشل تسجيل الدخول وإرسال "language": 2، تظهر الرسالة بالعربية لأن SessionLanguage يتم ضبطها بعد التحقق من كلمة السر، وبالتالي عند الفشل تسقط القيمة إلى الافتراضية (العربية).
الحل: تقديم سطر HttpContext.Items["SessionLanguage"] = command.Language ليكون أول سطر في الدالة قبل أي فحص لكلمة المرور.
