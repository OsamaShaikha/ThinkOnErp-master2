◆System Overview

Audit Logging

A channel-based, non-blocking pipeline that captures every meaningful state change across the platform. Events flow from application code through a resilient chain: in-memory channel → batch processing → circuit breaker → DB insert (with HMAC integrity). Falls back to JSON files when the database is unreachable.

16 event types · 3 trigger paths · 7 service interfaces · 3 controllers

Permissions

An implicit-grant + explicit-deny model with branch-scoped role/user permissions. SuperAdmin provisions systems to branches; screens and features auto-cascade from systems. Individual screens/features can be revoked per branch. Users and roles get fine-grained (screen, feature) permission overrides.

12 resolution steps · 2 permission entities · 3 provisioning tables · 3 controllers

1.3 Service Implementations

AuditLogger Infrastructure/Services/AuditLogger.cs

Core engine (921 lines). Uses Channel<AuditEvent> (bounded, BoundedChannelFullMode.Wait). Background task ProcessAuditEventsAsync() batches 50 events or 100ms window. Maps event types to SysAuditLog, enriches with legacy fields via LegacyAuditService (device ID, business module, error code, business description). Triggers IAlertManager for critical exceptions. Flushes remaining events on shutdown.

ResilientAuditLogger decorator adds circuit breaker + retry policy + file fallback. FileSystemAuditFallback writes JSON files with 100MB rotation.

PermissionService Infrastructure/Services/PermissionService.cs

8 logical steps (12 individual checks):

0User validation (null or inactive → deny)Deny
1Admin bypass (user.IsAdmin → grant)Bypass
2Active user check (BranchId == null → deny)Deny
3Screen validation (null or inactive → deny)Deny
4Branch provisioning — system assigned? (no → deny)Deny
5Branch provisioning — screen revoked? (yes → deny)Deny
6Branch provisioning — feature revoked? (yes → deny)Deny
7User explicit deny (yes → deny, overrides everything)Deny
8User explicit grant (yes → grant, overrides role)Grant
9Role validation (RoleId == null → deny)Deny
10Role explicit deny (yes → deny)Deny
11Role explicit grant (yes → grant)Grant
12Implicit grant (default → grant)Grant

LegacyAuditService Infrastructure/Services/LegacyAuditService.cs

1580 lines of backward compatibility. Transforms SysAuditLog into human-readable LegacyAuditLogDto. Generates business descriptions for 22 action types. Extracts device identifiers from User-Agent (POS terminals, kiosks, mobile, tablets, desktops, Postman, curl, ThinkOnERP apps). Maps IPs to departments. Generates sequential error codes. Caches SysSystem data with 30-minute TTL.

AuditTrailService Infrastructure/Services/AuditTrailService.cs

813 lines, ticket-specific. 12 methods all using DataChangeAuditEvent with action strings: INSERT, UPDATE, DELETE, STATUS_CHANGE, ASSIGNMENT_CHANGE, COMMENT_ADDED, ATTACHMENT_UPLOADED/DOWNLOADED, SEARCH, VIEW, AUTHORIZATION_FAILURE. Queries SysAuditLog directly for trails. Full search with pagination. Export to CSV/JSON.

AuditQueryService Infrastructure/Services/AuditQueryService.cs

1305+ lines query engine. Optional Redis caching (SHA256-hashed keys, cache-aside). Parallel query execution for date ranges > 30 days (chunks of 7 days). Oracle Text CONTAINS support with LIKE fallback. Role-based filtering: SuperAdmin → all, CompanyAdmin → company-scoped, regular → self only. User action replay with timeline visualization.

Integrity & Encryption Infrastructure/Services/

AuditLogIntegrityService (522 lines): HMACSHA256/512, canonical format id|actorId|action|entityType|entityId|creationDate|oldValue|newValue. Batch verification (100 per batch, 5 concurrent). Tampering detection alerts.

AuditDataEncryption (318 lines): AES-256-GCM with 12-byte nonce + 16-byte tag. Thread-safe via SemaphoreSlim(10). Configurable encrypted fields: password, token, creditCard, ssn, apiKey, secretKey, privateKey.

✓Phase 2 — Integration Done

2.1 Trigger Paths

Path 1: MediatR Pipeline

AuditLoggingBehavior.cs intercepts all IRequest<TResponse> commands (names ending in Command). Captures request state before, response after. For UPDATE/DELETE, captures old state via IEntityStateProvider. Fire-and-forget — never blocks the pipeline.

Path 2: ADO.NET Interceptor

AuditCommandInterceptor + AuditableOracleConnection + AuditableOracleCommand. Regex captures INSERT/UPDATE/DELETE table names. Skips SYS_AUDIT_LOG, SYS_AUDIT_LOG_ARCHIVE, SYS_AUDIT_STATUS_TRACKING. Logs the SQL operation with table name.

Path 3: Explicit Code

IAuditLogger.Log*Async() called directly from business logic. AuditTrailService provides 12 ticket-specific methods. MediatR pipeline behavior for automatic command auditing.

2.3 Authorization Handlers

AuditDataAuthorizationHandler

Enforces AuditDataAccess / AdminOnlyAuditDataAccess policies. SuperAdmin → full access. CompanyAdmin (role + companyId claims) → company-scoped. Regular user → self only.

MultiTenantAuthorizationHandler

Enforces MultiTenantAccess policy. Validates user's CompanyId matches resource's CompanyId. Branch-level checks BranchId match. Logs unauthorized attempts to ISecurityMonitor.

PermissionRequiredAttribute API/Authorization/PermissionRequiredAttribute.cs

Action filter: [PermissionRequired("screenCode", "featureCode")]. Extracts userId from JWT claim, calls IPermissionService.CanAccessByCodeAsync(). Returns 401 if no userId claim, 403 if access denied.

3.1 Audit Pipeline

App Code → IAuditLogger → Channel<AuditEvent> → ProcessAuditEventsAsync → ResilientAuditLogger → IAuditRepository → SYS_AUDIT_LOG
ResilientAuditLogger → Circuit Breaker → Retry Policy → Inner Logger | Fallback → FileSystem

3.2 Permission Resolution

PermissionRequiredAttribute → IPermissionService → 8-Step Chain → Grant / Deny
CompanyPermissionsController → Role/User Permission Repos → SYS_ROLE/USER_SCREEN_PERMISSIONS

    SysCompany (1) ──> (N) SysBranch (1) ──> (N) SysBranchSystem   ← grant (systems assigned to branch)

                    │                           └── SysBranchFeature   ← deny-list (features revoked at branch)

                    └── (N) SysUser (N) ──> (M) SysRole
