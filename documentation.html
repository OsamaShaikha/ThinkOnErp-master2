معمارية محرك الضرائب لمطوري الواجهات (Tax Engine UI Architecture)

🎯 الهدف الأساسي من المحرك في الـ Frontend:

محرك الضرائب هو نقطة الارتكاز لجميع عمليات احتساب القيمة المضافة وفك الأسعار الشاملة وغير الشاملة وتوليد قيود اليومية المقترحة وكود الفاتورة الإلكترونية ZATCA QR. لا تحتاج الواجهة لأي معادلات رياضية معقدة، بل ترسل البيانات للمحرك وتستقبل التفقيط المحاسبي الكامل بدقة السنت.

الـ Base Route الموحد:
/api/accounting/tax
نظام الحماية والتوثيق:
Authorization: Bearer <token> (Tenant-Scoped)

🗺️ خريطة شاشات الـ UI المرتبطة بمحرك الضرائب:

شاشة الـ UI الـ Endpoint المستدعى وقت وطريقة الاستدعاء
فواتير المبيعات / المشتريات POST /api/accounting/tax/calculate عند إدخال الأصناف أو تعديل الكمية والسعر والخصم أو تبديل خيار (شامل الضريبة).
طباعة ومعاينة الفاتورة POST /api/accounting/tax/zatca-qr عند فتح شاشة الطباعة أو إصدار PDF لتوليد الـ QR Code المعتمد لهيئة الزكاة.
لوحة الإقرار الضريبي GET /api/accounting/tax/vat-declaration عند اختيار الفرع والفترة لاستخراج مربعات الإقرار (Boxes 1-16) وصافي المستحق.
القوائم المنسدلة للنسب GET /api/accounting/tax/rates عند تحميل شاشة الفاتورة لتعبئة قائمة اختيار النسبة (15%, 5%, 0%, معفى).

💡 تعليمات مطور الواجهة (UI Integration Guide):

1. في جدول سطور الفاتورة، اربط هذا الـ API مع حدث التغيير (onChange) للكمية، السعر، الخصم، وكود النسبة، مع إضافة Debounce (300ms).
2. عند تفعيل خيار isInclusive: true، سيقوم السيرفر بفك الضريبة من السعر تلقائياً وإعادة السعر الصافي بدون ضريبة في netBaseAmount.
3. استخدم data.lines[i].taxAmount لعرض ضريبة السطر، و data.lines[i].lineTotal لعرض إجمالي السطر، و data.grandTotalAmount في فوتر الفاتورة.

الـ Request Body Required:
TaxCalculationRequestDto (JSON)
الـ Response Type:
ApiResponse<TaxCalculationResultDto>

إدارة النسب الضريبية (Tax Rates CRUD)

💡 تعليمات مطور الواجهة:

تُستخدم في شاشة إعدادات الضرائب (Tax Setup Admin Panel) لإنشاء وتعديل وحذف النسب الضريبية للشركة.

1. إنشاء نسبة جديدة: POST /api/accounting/tax/rates

{
  "taxRateCode": "VAT_5",
  "taxCategoryId": 1,
  "nameAr": "ضريبة القيمة المضافة المخفضة (5%)",
  "nameEn": "Reduced VAT (5%)",
  "ratePercent": 5.0,
  "rateType": "PERCENTAGE",
  "salesTaxGlAccountCode": "213101",
  "purchaseTaxGlAccountCode": "113101",
  "isExempt": false,
  "isZeroRated": false,
  "displayOrder": 4
}

2. تعديل نسبة: PUT /api/accounting/tax/rates/{id}

3. حذف نسبة: DELETE /api/accounting/tax/rates/{id}

فئات الضرائب (Tax Categories CRUD)

💡 تعليمات مطور الواجهة:

تصنيفات الضرائب العامة (مثل: VAT ضريبة القيمة المضافة، WHT ضريبة الاستقطاع، EXCISE الضريبة الانتقائية).

Method Route الوصف
GET /api/accounting/tax/categories استرجاع جميع الفئات الضريبية
POST /api/accounting/tax/categories إنشاء فئة ضريبية جديدة

المجموعات الضريبية المركبة (Tax Groups CRUD)

💡 تعليمات مطور الواجهة:

تُستخدم عند تطبيق أكثر من ضريبة على نفس الصنف بترتيب معين أو بطريقة تراكمية (Compound Tax).

Method Route الوصف
GET /api/accounting/tax/groups استرجاع المجموعات الضريبية
POST /api/accounting/tax/groups إنشاء مجموعة ضريبية مركبة
