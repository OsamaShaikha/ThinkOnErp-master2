1. مشكلة التكرار اللانهائي في تحويل الـ JSON (Object Cycle Exception)

الواجهات المتأثرة: GET & POST /api/hr/loans, POST /api/hr/loans/1/approve, GET & POST /api/hr/work-calendars.
السبب: تقوم الـ Controllers بإعادة الكيان المباشر (Domain Entity) بدلاً من DTO. حيث يمتلك WorkCalendar علاقة متبادلة مع WorkCalendarDay، ويمتلك EmployeeLoan علاقة متبادلة مع LoanRepaymentSchedule. فيكتشف محول System.Text.Json دورة مرجعية متكررة ويرمي JsonException ينتج عنها خطأ خادم 500.

الحل الفوري: تفعيل ReferenceHandler.IgnoreCycles في Program.cs أو إعادة DTOs مستقلة بدلاً من Entities.

2. استثناءات التكامل المرجعي لقاعدة البيانات (Foreign Key Violation Unhandled in Middleware)

الواجهات المتأثرة: POST /api/hr/adjustments, POST /api/hr/employees.
السبب: عند إرسال قيمة غير موجودة مثل ComponentCode أو PositionCode، يرمي محرك أوراكل ORA-02291 parent key not found وتتحول إلى DbUpdateException. وحيث أن ExceptionHandlingMiddleware لا يلتقط هذا الاستثناء، يخرج الرد كـ 500 بدلاً من إرجاع 400 Bad Request مع توضيح الحقل غير الصالح.

الحل الفوري: إضافة معالج لـ DbUpdateException في ExceptionHandlingMiddleware لترجمة أخطاء الـ FK إلى 400 Bad Request للمستخدم.
